# Terpene transcriptomics paper: public evidence snapshot

This directory is a public snapshot of the transcriptomics project in Terpedia/research, taken from commit `cf9020c4181948b74b5d3dbeaa4c30c7a9e7223f` on 26 October 2026. It provides stable GitHub links while `research.terpedia.com` is unavailable. The source project remains the editorial home; this copy is not automatically synchronized.

- [Full biological white paper](manuscript/white-paper.md)
- [Claim-to-source ledger](manuscript/claim-ledger.md)
- [Critical review](manuscript/critical-review.md)
- [Selected datasets and sample design](manuscript/selected-datasets.md)
- [Pilot linalool notebook](notebooks/terpene_exposure_pilot.ipynb)
- [A549 Perturb-seq context notebook](notebooks/signaling_context_comparison.ipynb)

The notebooks, scripts, source manifests, processed inputs, and result tables are retained in their original relative paths so the paper's local citations and figures resolve. The separate [Terputer executed transcriptomics notebook](../../notebooks/terputer-transcriptomics.ipynb) covers the GSE138291 comparison and is the current report-pipeline example.

These analyses are descriptive. Shared controls, processed expression units, unmatched exposure designs, and limited independent replication prevent claims of a reproducible pathway, a context interaction, or a terpene target dependency.

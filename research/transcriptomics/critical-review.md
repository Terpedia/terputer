# Critical review of the Terputer transcriptomics white paper

**26 October 2026 · Author-side review of the published working methods note**

## Overall judgment

The draft is a credible **methods demonstration** with unusually clear caveats. It does not answer the stated biological question or yet demonstrate that Terputer chat can complete the workflow end to end. I would not publish the current results as a finding about reproducible terpene pathways or target-specific responses.

## Findings, in priority order

1. **Resolved high-severity defect — The summary artifact had mislabeled results.** The review found that `rows` was reused for PIE target comparisons and GSE138291 arm pairs, causing fungal records to appear under `perturbseq.records`. The notebook has since been corrected and rerun: the summary now contains two PIE target records and six separate fungal arm comparisons. Earlier copies of the summary should be discarded.
2. **High — The central question remains unanswered.** The original executed notebook analyzes one bacterial linalool matrix and one fungal multi-arm matrix. Three later project notebooks audit publisher supplementary tables for fungal linalool or limonene exposure; the GSE157638 MRSA and GSE276099 HepG2 notebooks audit processed expression matrices. None is an independent raw-count reanalysis. The MRSA and Botrytis studies provide an exact-compound, different-organism comparison candidate, but no cross-study orthology or pathway model has been fitted. The HepG2 β-caryophyllene cohort adds one human cell-line context with fractional count estimates, not a replicated context interaction. The [cohort triage](terpinen-4-ol-cohort-triage.md) holds PRJNA729806 until control provenance is resolved.
3. **High — The GSE138291 correlation can be inflated by the shared control.** The two reported log2 ratios subtract the same untreated mean feature by feature. This creates covariance even if treatment-specific effects differ. The leave-one-control-out exercise retains a shared control and does not remove this dependency. The 0.433 correlation and 64.8% sign agreement should be described only as properties of these derived vectors. A direct treated-arm comparison, replicate-level model, or independent-control analysis is needed.
4. **High — The notebook workflow and agent workflow remain distinct.** The notebook was executed with `nbclient` in the local Python environment, not through an observed Terputer chat tool call. The repository's in-app research agent now requires a personal Terpedia API key and routes model calls through the Terpedia backend, but the live backend does not yet serve the key endpoints. The earlier remote MCP and read-only BigQuery adapter were verified for metadata lookup; that does not demonstrate an end-to-end member-authenticated chat analysis. The paper must distinguish implemented interfaces, executed notebook analysis, and live metadata services.
5. **Medium — The A549 comparison is weak evidence for context dependence.** Only BATF2 and PARP12 overlap in the selected published summaries. Low correlations across feature-level effect estimates can reflect noise, near-zero effects, gene filtering, or differences in uncertainty. No biological-replicate effect model or significance of context interaction was assessed. This example is useful for workflow design, but the results table should avoid the unqualified phrase “effects differ across these contexts.”
6. **Medium — The linalool interpretation is too broad.** Direction counts across nearly all FPKM features and the much higher treated sample medians may indicate a global measurement or normalization issue. Those counts are not a differential-expression result, and the unresolved `geneN` identifiers preclude metabolic or signaling interpretation. The source culture independence and metadata should be verified.
7. **Medium — Source and version tracking are incomplete.** The rerun notebook verifies three downloaded data-file hashes, and its execution receipt now pins all four downloaded expression files, three local manifests, and the two helper-code files used by the notebook. The generated brief links the four download URLs to those hashes. GSE138291 still lacks a separate retrieval manifest with retrieval time and source revision; the notebook verifies its hash in a cell. The requirements remain version ranges, and the receipt records the installed versions for this run rather than an independently recreated environment.
8. **Medium — BigQuery records need curation before load.** The locally prepared JSONL now contains nine studies, 70 samples, 12 contrasts, and 34 observations, including ten GSE263903 sample metadata rows and bounded single-cell observations. The last verified live adapter returned four studies, 33 samples, two descriptive observations, and no contrasts; the expanded files have not been applied to BigQuery. The proposed schema still lacks feature-level evidence, biological replicate linkage, and analysis-run lineage. The MCP Worker can serve a commit-pinned public snapshot when the adapter is unavailable or incomplete, but that does not make the new rows present in BigQuery.
9. **Resolved medium — Generated briefs hid claim limitations.** Each report specification contained a `limitation` field, but the white-paper renderer printed only claim text and links. The regenerated briefs now place caveats beside results and interpretation and state the relevant claim with its caveat in the limitations section. This improves presentation; it does not independently validate the claim.

## Claim assessment

| Claim | Current status |
| --- | --- |
| Terputer can preserve source provenance and run a notebook | Demonstrated locally; the summary-artifact defect was corrected and rerun. |
| Two pure compounds have partly aligned fungal response vectors | Descriptive within-study observation; shared-control dependency limits interpretation. |
| Linalool induces a specific metabolic or signaling program | Unsupported by the processed matrix analysis. |
| Terpene responses reproduce across contexts | Not tested. |
| Any response depends on a specific chemical target | Not established by the analyzed data. A beetle article reports higher terpinen-4-ol mortality after CYP9Z6 or GSTs7 RNAi, but the phenotype has not been independently audited here and does not prove direct binding; its public RNA-seq archive currently exposes only treated runs. |
| Terpedia BigQuery serves curated transcriptomics evidence | The last verified adapter response covered four studies, 33 samples, and two descriptive observations, with no contrasts. Six-study expanded records remain staged locally; the Worker also has a pinned public snapshot. |

## Publication recommendation

The notebook summary has been fixed and rerun. The [full biological white-paper snapshot](../terpene-transcriptomics/manuscript/white-paper.md) includes a [claim-to-source ledger](../terpene-transcriptomics/manuscript/claim-ledger.md) and the Codebreaker role mapping. This Terputer note can be published as a technical methods demonstration. A biological result about reproducible pathways still requires raw-count analysis of independent exposure cohorts with stable gene/pathway mappings and explicit uncertainty. A target-specific paper would additionally need chemical-genetic interaction or direct target-engagement evidence.
